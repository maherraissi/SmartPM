# 🚀 Architecture & Historique du Système SmartPM (Norme DO-178C)

Ce document constitue le registre central de la plateforme SmartPM. Il détaille la structure technique, les choix technologiques et le rôle de chaque composant pour assurer la conformité aux standards aéronautiques de haut niveau.

---

## 🏗️ Vision & Architecture Globale
SmartPM est une **Engineering Execution & Competency Platform** dédiée au cycle de vie logiciel **DO-178C**. Elle ne se contente pas de gérer des tickets, elle orchestre la production d'artefacts critiques avec une ségrégation stricte des rôles.

### 🧩 La Triade Technologique :
1.  **Backend (Port 3000)** : Développé avec **NestJS**, moteur robuste gérant la logique métier, l'authentification et les connexions à la base de données **MongoDB Atlas**.
2.  **Frontend (Port 4200)** : Une Single-Page Application (SPA) moderne sous **Angular 18+** (mode Standalone), offrant des interfaces "Cockpit" pour chaque profil d'utilisateur.
3.  **AI Service (Port 8000)** : Microservice **Python (FastAPI)** agissant comme le cerveau intelligent pour l'auto-planning, l'analyse de risques et le support technique via LLM.

## 📁 Dictionnaire Exhaustif des Fichiers

### 1. 📂 Racine du Projet (`/`)
*   `package.json` : Définit les scripts de démarrage synchronisés via `concurrently`. La commande `npm run dev` lance simultanément le Backend, le Frontend et l'IA.
*   `README.md` : Guide d'installation et de configuration globale.
*   `historique.txt` : Ce document (votre source de vérité).

### 2. ⚙️ Backend Services (`/backend/src/`)
*Structuré par domaines métier (Modules).*

#### 👥 Users & Auth (`/user/`)
*   `user.schema.ts` : Définit l'utilisateur aéronautique avec ses **certifications** (HLR, LLR, LLT, etc.) et ses rôles (`ADMIN`, `MANAGER`, `MEMBER`).
*   `user.service.ts` : Gère le cycle de vie des membres et les matrices de compétences.

#### 📊 Projects & Teams (`/project/`)
*   `project.schema.ts` : Structure les projets avec suivi de progression, dates clés et assignation d'équipe.
*   `project.service.ts` : Cœur de la gestion de projet, incluant la logique complexe de déploiement et de statistiques.

#### 📝 Tasks & Compliance (`/task/`)
*   `task.schema.ts` : Fichier CRITIQUE. Gère l'indépendance obligatoire (**Author != Reviewer**). Stocke les IDs de conformité et le tracking temporel.
*   `task.service.ts` : Implémente le **Moteur Temporel Aéro** (calcul des dates ignorant les week-ends, basé sur 7h/jour).

#### 🔔 Notifications & Templates
*   `notification.service.ts` : Envoie des alertes en temps réel lors de l'assignation de tâches ou de commentaires.
*   `function-template.schema.ts` : Bibliothèque de plus de 60 fonctions standards pré-approuvées pour les phases de développement.

### 3. 🎨 Frontend App (`/frontend/src/app/`)
*Interface utilisateur haut de gamme.*

#### 🧩 Composants Clés (`/components/`)
*   `ai-chatbot/` : Interface de l'assistant SmartPM (Design "Glassmorphism").
*   `manager-dashboard/` : Vue de gestion pour les managers (Auto-planning AI, suivi de charge).
*   `member-dashboard/` : Vue simplifiée pour les ingénieurs (Tâches en cours, formations).
*   `project-wizard/` : Formulaire par étapes pour la création de projets avec sélection intelligente de l'équipe.
*   `project-detail/` : Interface "Wow" affichant les détails d'un projet, les métriques et les interactions.

#### 📡 Services & Guards (`/services/`, `/guards/`)
*   `ai.ts` : Client pour communiquer avec le service Python (Streaming de réponses).
*   `project.ts` & `task.ts` : Appels API vers le backend NestJS.
*   `auth-guard.ts` : Protège les routes selon les rôles utilisateurs.

### 4. 🧠 Intelligence Artificielle (`/ai/`)
*Moteur de décision basé sur les LLMs.*

*   `main.py` : Application FastAPI.
    *   **Route `/chat`** : Utilise **Gemini 2.5 Flash** (primaire) et **OpenAI gpt-4o-mini** (fallback) pour répondre aux questions sur les données du projet.
    *   **Logic de Prompt** : Injecte le contexte MongoDB en temps réel pour des réponses précisées.
*   `.env` : Clés API Cloud (Google & OpenAI).
*   `venv/` : Environnement Python isolé avec les dépendances (FastAPI, Google AI, Motor).

## 🛠️ Fonctionnalités Spécifiques & Sécurité
*   **Règle d'Indépendance (DO-178C)** : Le système interdit nativement qu'une personne soit à la fois auteur et vérificateur d'une même tâche.
*   **Audit Trail** : Chaque action sur une tâche est tracée.
*   **UI Cockpit** : Design professionnel avec dégradés harmonieux, effets de lévitation ("hover") et réactivité maximale.
*   **IA Contextuelle** : L'IA ne discute pas "génériquement", elle connaît vos projets, vos tâches et votre équipe grâce à l'intégration directe de MongoDB.
